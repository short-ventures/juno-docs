description: "How to give Juno useful tasks and review the work it returns."

Delegating work to Juno works best when you describe the outcome instead of only naming a tool.

## Write a clear task

Include the result you want, the source Juno should use, and what should happen next.

<AccordionGroup>
  <Accordion title="Good task">
    Review last week's Meta Ads performance, identify the campaigns with weak conversion rates, and create a short action plan in a table.
  </Accordion>
  <Accordion title="Less useful task">
    Look at ads.
  </Accordion>
</AccordionGroup>

## Give context early

Add links, files, workspace details, brand constraints, audience notes, deadlines, and examples of acceptable output. If Juno needs access to a connector or credential, it will ask for the connection before it can use that tool.

## Review and redirect

Juno can continue from the work it has already done. Ask for revisions, narrower analysis, a different format, or a follow-up task in the same thread.

## Keep work scoped

Large requests are easier to review when you split them into a first pass and a second pass. Start with research, audit, or planning. Then ask Juno to execute the approved changes.
