<Update
  label="July 29, 2026"
  rss={{
    title: "Reliable screenshot inspection",
    description: "Juno now inspects saved screenshots through its image reader without interrupting task conversations."
  }}
>
  - Browser screenshots now stay in the workspace while Juno follows their file paths to inspect them, avoiding unsupported direct image requests.
</Update>

<Update
  label="July 27, 2026"
  rss={{
    title: "Faster task starts during background work",
    description: "Juno now reserves dedicated capacity for task conversations so background orchestration does not delay them."
  }}
>
  - Task conversations now run on capacity isolated from background workspace orchestration, so they can start promptly even when several long-running background jobs are active.
</Update>

<Update
  label="July 27, 2026"
  rss={{
    title: "Shared artifacts by default",
    description: "New artifacts, databases, and published sites now belong to the workspace by default, so teammates can collaborate without sharing private tasks or chats."
  }}
>
  - New documents, tables, pages, calendars, galleries, canvases, databases, and published sites are now available to every teammate in the workspace by default.

  - Teammates can open, edit, duplicate, download, and preview shared artifacts without needing access to the task that created them.

  - Tasks and chats remain private, and public artifact links remain a separate sharing option.
</Update>

<Update
  label="July 27, 2026"

  }}

  - Browse the full icon library in a compact picker and use the expanded color palette to make artifacts easier to recognize.

<Update
  label="July 24, 2026"
  rss={{
    title: "Manage artifacts, databases, and sites from workspace folders",
    description: "Juno now gives databases their own workspace folders and keeps folder removal in sync with artifacts, databases, and published sites."
  }}
>
  - Every database now has a canonical folder in `/workspace/databases`, separate from its table, gallery, and calendar views in `/workspace/artifacts`.

  - Removing an artifact folder removes only that view, so its backing database and other linked views remain available.

  - Removing a database folder removes the database and all of its linked artifact views. Removing a published site folder removes the site and its public route too.
</Update>

<Update
  label="July 22, 2026"
  rss={{
    title: "Shared workspace files and self-contained artifacts",
    description: "Juno now gives tasks a shared workspace and keeps each artifact together with its supporting files."
  }}
>
  - Tasks now work from a shared `/workspace`, so files can carry across task conversations without being locked inside task-specific folders.

  - Each artifact now has its own folder for its content, images, assets, and other supporting files, making related work easier for Juno to find and keep in sync.

  - Artifact folders include generated configuration that Juno manages automatically, keeping artifact previews and file changes aligned.

  - Databases and published sites are now shared across the workspace, so any task can discover and continue working with them regardless of where they were created.
</Update>

<Update
  label="July 21, 2026"
  rss={{
    title: "Continuous tasks and workspace-owned artifacts",
    description: "Juno now keeps task identity and context consistent across longer conversations while making Library artifacts available across the workspace."
  }}
>
  - The chat picker is now **Tasks**, so you can return to a named task without managing its individual conversation history.

  - When an older task needs a fresh conversation, Juno starts it automatically and carries the relevant compacted context forward.

  - Artifacts in the Library now belong to the workspace and remain available independently of the task where they were created.

  - You can create tables, documents, pages, calendars, galleries, and canvases directly from the **+** menu at the end of the workspace tabs.
</Update>

<Update
  label="July 20, 2026"
  rss={{
    title: "Queue follow-up prompts during tasks",
    description: "Juno now lets you queue follow-up instructions while a task is still running."
  }}
>
  - You can now press Enter to queue another prompt while Juno is working, without stopping the active task.

  - Queued prompts stay visible as pending, run in order, and leave the **Stop** action available for the current task.
</Update>
