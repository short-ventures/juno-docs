<Update
  label="June 24, 2026"
  rss={{
    title: "Team and mailbox access",
    description: "Juno now gives teams clearer controls for teammate access and workspace mailbox senders in settings."
  }}
>
  - Team owners can invite teammates from settings, revoke pending invitations, and send secure invite links for new members to accept.

  - Workspace mailbox settings now let team owners update Juno's mailbox address, and each teammate can approve alternative email addresses they use to communicate with Juno.

  - Removing a teammate now keeps their old workspace tasks with the team, signs them out of active sessions, and revokes their approved mailbox senders.
</Update>

<Update
  label="June 24, 2026"
  rss={{
    title: "Clearer connector credential recovery",
    description: "Juno now gives clearer next steps when a connector needs fresh credentials before it can run."
  }}
>
  - When connectors reject missing, expired, or invalid credentials, Juno now asks for a secure credential update instead of showing a raw authentication error.
</Update>

<Update
  label="June 24, 2026"
  rss={{
    title: "Share selected task artifacts",
    description: "Juno can now create read-only links for selected task artifacts and open them in a shared artifact workspace."
  }}
>
  - You can now create one read-only link for all or selected artifacts in a task, with sharing available from both desktop and smaller screen layouts.

  - Shared artifact links now open in a read-only workspace with tabs, overview cards, previews, and downloads for supported artifacts.

  - Document artifact slash menus stay open while you move into the menu, and their section labels now match the workspace menu style.
</Update>

<Update
  label="June 22, 2026"
  rss={{
    title: "Cleaner app sidebar navigation",
    description: "Juno's sidebar is easier to scan, works better when collapsed, and keeps workspace and task controls close at hand."
  }}
>
  - The app sidebar has been tightened up with clearer primary navigation, workspace switching at the top, and a compact collapsed mode that still keeps tasks, settings, documentation, and your user menu within reach.

  - Task navigation is easier to manage from the sidebar: pinned tasks stay grouped at the top, unread tasks are marked more clearly, and pin/archive controls no longer get in the way of opening a task.

  - Desktop layouts now handle hidden and floating sidebars more cleanly, with clearer open/close labels and topbar spacing that stays out of the way of window controls.
</Update>

<Update
  label="June 18, 2026"
  rss={{
    title: "Faster multi-step task runs",
    description: "Juno can now make faster progress when a task has several independent actions to complete."
  }}
>
  - Multi-step tasks can now make progress on independent actions at the same time, reducing wait time when Juno needs to gather information, inspect files, or use connected tools.

  - Live task progress updates remain stable while work finishes in the background, so completed steps can appear as soon as they are ready.
</Update>

<Update
  label="June 15, 2026"
  rss={{
    title: "Improved connector credential handling",
    description: "Juno now asks for missing connector credentials before trying authenticated Ahrefs actions."
  }}
>
  - Ahrefs connector discovery now checks for saved credentials before contacting Ahrefs, so Juno can ask you to connect the account instead of retrying without authentication.

  - Connector errors now stay clearer when credentials are missing, reducing failed task runs caused by unauthenticated discovery requests.
</Update>

<Update
  label="June 10, 2026"
  rss={{
    title: "Document and connector improvements",
    description: "Document artifacts are more reliable, and connected tools can now work with uploaded files."
  }}
>
  - Document artifacts now handle complex content more reliably, including markdown mixed with HTML, code snippets, tables, and unusual formatting.

  - Third-party connectors are more resilient when optional capabilities are unavailable, reducing noisy failures from connected tools.

  - Connected tools can now use files from your task workspace when an action requires an upload.
</Update>
