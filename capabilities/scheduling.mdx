Juno can schedule tasks so work happens later or repeats on a cadence.

## Use scheduling for

- Weekly reporting
- Recurring audits
- Follow-up reminders
- Monitoring workflows
- Routine data pulls or summaries

## Creating a schedule

Describe the work, the cadence, and the expected output. Include the connector or source Juno should use, such as a spreadsheet, ad account, CRM, or website.

Scheduled work should have a narrow scope and a clear review path so the results remain useful over time.
