Juno runs tasks inside a managed cloud computer. This gives the agent a place to browse, work with files, run scripts, and keep task artifacts together.

## What it is for

- Opening websites and web apps
- Reading and writing files during a task
- Running command-line tools when a connector needs local processing
- Producing artifacts such as documents, spreadsheets, images, reports, and exports

## What to expect

The cloud computer is task-focused. Juno uses it to complete the work you delegated, then returns the relevant result, artifact, or summary.

If a task needs access to a private tool, Juno will use the connected connector or ask for the missing credential.
