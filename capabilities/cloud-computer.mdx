Most general AI tools use your computer to get work done - but that's limiting. What if you're offline, for example?

Juno has its own cloud computer, which it can interact with however it sees fit to help you complete tasks.

This means that even while you're lying on a beach, Juno can be getting work done without any change in its abilities.

Additionally, it provides a security benefit by not running commands on your local computer, as many generic tools do.

## What it is for

- Creating, searching and managing files
- Using packages to manipulate data and fetch content
- Working with different user-uploaded file types
- Creating or analyzing images
- Producing artifacts such as documents, spreadsheets, images etc

## What to expect

Juno uses its computer as its primary work surface. You won't necessarily know when it is using its computer, but it's safe to assume it is using its computer whenever its getting work done for you.

You can use the chatbox history to see when computer commands are being used.
