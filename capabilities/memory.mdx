Juno uses workspace context so repeated work does not start from scratch.

## What memory is useful for

- Brand voice and style guidance
- Important company facts
- Reusable files and source materials
- Tool and connector context
- Lessons from previous work

## Keep memory accurate

Tell Juno when a fact, preference, or source file has changed. Good memory should be durable, specific, and useful across more than one task.

Avoid storing temporary instructions as long-term guidance.
