Marketing work lives across too many tools: CRM, ad accounts, inboxes, spreadsheets, analytics and content systems. Plugins let Juno work with those tools using the access that you have explicitly approved.

This means Juno can use real campaign data, customer context, and data pro-actively, just like a human coworker would.

## Adding your tools and data

### Connecting using chat

The simplest way to add a plugin is to simply ask Juno. It will then let you know if the plugin is available and present a secure dialog for you to authorize acess.\

<Frame>
  ![Screenshot 2026 06 14 At 18 59 04](/images/Screenshot-2026-06-14-at-18.59.04.png)
</Frame>

From there, you can begin delegating work that uses this plugin immediately and across future tasks.

### Connecting using the manager

Alternatively, you can explore the plugin library from the side navigation.

<Frame>
  ![Image](/images/image-1.png)
</Frame>

This enables you to:

- Add new plugins
- Re-authorize existing plugins
- Remove plugins
