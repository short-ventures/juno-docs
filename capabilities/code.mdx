Most marketing work should not require you to code - but some tasks are faster, safer, or more precise when code does the repetitive part.

Juno can write and run code on its own cloud computer to clean data, inspect files, automate checks, or make technical edits.

You do not need to write the code yourself. Juno uses code as a work method, then returns the result in plain language.

## What it is for

- Cleaning and reshaping CSVs, spreadsheets and structured data
- Checking links, tracking parameters, exports and reports
- Editing HTML, CSS, Markdown and other source files
- Creating small scripts for repeatable marketing operations
- Diagnosing errors in files or technical workflows

## What to expect

Juno uses code when it needs precision or repeatability. It may show command activity in chat history.

Review any code or file changes before using them in a live site, campaign, or production workflow. Ask Juno to explain the diff or run checks if the change matters.
