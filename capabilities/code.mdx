Juno can write, run, and revise code when a task needs more precision than manual steps. You do not need to code yourself; Juno uses code as another capability while it works.

## What code is useful for

- Cleaning, transforming, or validating structured data
- Writing scripts for repeatable workflows
- Editing HTML, CSS, Markdown, CSVs, and other source files
- Inspecting errors and making targeted fixes
- Creating small utilities that support a larger delegated task

## Good code tasks

- Clean this CSV and create a normalized version with consistent columns.
- Update this landing page copy and keep the existing structure intact.
- Generate a script that checks every campaign URL for missing UTM parameters.
- Fix the formatting issue in this exported report.

## Review before shipping

When Juno produces code or edits source files, review the result before deploying it or using it in a production workflow. For risky changes, ask Juno to explain the diff and run the relevant checks.
