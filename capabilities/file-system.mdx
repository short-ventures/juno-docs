Most delegated work creates material along the way: source files, notes, exports, drafts and final artifacts.

Juno can read, create, and update files on its cloud computer so work stays organized as the task progresses.

This means you can upload materials, ask Juno to combine them, and receive durable outputs such as documents, spreadsheets, images, or reports.

## What it is for

- Reading uploaded source files
- Creating and updating task artifacts
- Comparing documents, spreadsheets, images and structured data
- Keeping intermediate files organized during a task
- Turning several inputs into one final deliverable

## What to expect

Tell Juno which files matter and what should happen to them. It can summarize, transform, compare, clean, or package files as part of the task.

When Juno creates a file you plan to use externally, review the artifact before sharing or publishing it.
