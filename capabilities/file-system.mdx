Juno can read, create, and update files while it works on a task. Files make work durable across research, analysis, and final deliverables.

## Files Juno can work with

- Uploaded source files
- Generated task artifacts
- Workspace guidance files
- Documents, spreadsheets, images, and structured data

## Working with files

Tell Juno which files matter and what should happen to them. For example, you can ask Juno to summarize a document, update a spreadsheet, compare two files, or create a final report from several sources.

When Juno creates an artifact, review it before using it externally.
