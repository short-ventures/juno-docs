# Contribute to the documentation

This repository contains the Juno documentation site.

## Local development

1. Clone the repository.
2. Install the Mintlify CLI: `npm i -g mint`.
3. Make your changes.
4. Run `mint broken-links`.
5. Commit your changes and open a pull request.

To preview the site, run `mint dev` from the repository root and open the local Mintlify URL.

## Writing guidelines

- Use active voice.
- Address the reader directly.
- Keep sentences concise.
- Lead with the goal.
- Use consistent terminology.
- Include examples when they clarify a workflow.
